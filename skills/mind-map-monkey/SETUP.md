# Mind Map Monkey setup

Mind Map Monkey is a personal Cowork skill. It turns documents, web pages, video transcripts and Teams meeting transcripts into an editable Mermaid mind map (`.mmd`). It saves the map to your OneDrive for Business and gives you a link that opens it in the Mind Map Monkey app.

## What you need

- A work account with OneDrive for Business.
- Access to a Copilot Managed Runtime app named Mind Map Monkey. The skill looks the app up each time it runs, so no app ID is stored in the skill.
- Access to the files, pages or meetings you want to map.

## Install

1. Put the `mind-map-monkey` folder in `Documents/Cowork/skills/` in your OneDrive. You can also ask Cowork to install it, and Cowork will show an approval card.
2. Open a new Cowork conversation and ask "show my skills" to check that Mind Map Monkey is listed.
3. Try it out by asking "make a mind map from this document" with a file attached.
